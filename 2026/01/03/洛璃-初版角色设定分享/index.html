洛璃--初版角色设定分享

2026-01-03
Uncategorized
6.8k words
  • 洛璃的小窝

之前说过会给洛璃补全人设，现在来啦~

虽然说是初版设计，但是其实已经迭代过好几次了…

1. 基本人物设定

  • 姓名：洛璃（Rakuri）

  • 性别：女

  • 种族：沃佩（Vulpes）·银狐亚种

    • 具备人类体征，保留银狐耳与蓬松尾部；感官灵敏度远高于常人，尤其听觉与触觉。

  • 职业：战术魔导工匠 / 晶体共鸣者（Field Technomancer）

    • 编制定位：特殊行动部门随队的“前线技术支援 + 远程火力平台”。主要职责包括：装备维护/改装、战场仪器校准、晶体阵列部署与远程压制。对外自称“后勤技术人员”，拒绝“战斗法师”头衔。

2. 角色外貌

  • 身高/体型：

    • 170cm（含耳高）/ 修长纤细型：肩线窄、腰胯比例干净利落，肌肉不夸张但线条紧致，呈现“长期高强度任务下的轻量化体态”。
    • 站姿习惯重心偏稳、脚尖微外，像随时在做“受力与弹道预估”。

  • 发色/发型：

    • 钛银长直发如液态月光，发梢渐变冰蓝；发量偏多但丝滑顺直，移动时像一整片冷光瀑布。
    • 战斗/启动晶体阵列时，受静电与共鸣场牵引：发丝会出现“微失重漂浮”，细碎发梢像被无形风场托起，形成“悬浮的冷雾边缘”。
    • 右侧固定一枚黑色金属发卡式通讯模块（兼作固定刘海与信号节点），边角带细微荧光指示点。

  • 瞳色/眼神：

    • 冰河蓝通透瞳，虹膜边缘带极淡的冷灰环，像“镜头镀膜”。
    • 工作模式：目光聚焦稳定、眨眼频率低，像高精度扫描仪锁定目标。
    • 待机模式：眼睑半垂、视线略散，呈现明显“低电量”慵懒与疲惫。

  • 标志性服饰：

    • 内层（贴身战术装甲衣）：高机动白色聚合物紧身装甲衣，胸腹与关节处嵌入模块化护甲板，拼接缝线极少，强调“低阻力/易清洁/可快拆维护”。
    • 外层（战术大衣）：深空灰立领长外套，肩部装甲过渡自然，袖口与内衬为渐变荧光青的高流体材质；行动时内衬会像“呼吸灯”一样在阴影里闪烁。
    • 腿部与护具：大腿外侧有一圈轻型合金腿环/能量锁扣（用于固定装甲模块与能量回路），膝部护板为“瓷白硬壳”质感。
    • 武装（合金法杖）：银灰合金杖身，顶端为磁悬浮几何能量晶体（多枚三棱晶片），周围伴随细小电弧与微光粒子，像一组被“算力”驯服的漂浮公式。
    • 日常服饰：任务结束后会换成宽松浅灰卫衣 + 深灰运动长裤，整个人从“冷硬机甲感”瞬间变成“抱尾巴取暖的小动物”，形成强烈反差。

  • 整体配色：

    • 主色调：钛白（装甲/发色高光） + 深空灰（大衣主体）。
    • 辅色调：冷银灰（金属件/杖身/肩甲）。
    • 点缀色：高饱和荧光青（能量回路、袖口、内衬、指示灯），用来强化“冷凝科技/低温电弧”的氛围。

  • 视觉特征：

    • 银狐耳与巨尾：耳内绒为淡粉灰，耳尖更冷；尾巴极蓬松、体积感强，像一团柔软的银白云。
    • 能量抑制环（尾根）：金属质感束环嵌入细薄发光刻线，像“对不稳定力量的强制限幅器”，既是束缚也是安全阀——视觉上形成“野性被精密锁住”的张力核心。
    • 装甲质感对比：身体是“瓷白硬壳 + 无缝贴合”，而尾巴是“柔软绒羽”，两者同框时天然产生“机械/生命”的强辨识度。

3. 角色核心 (Core)

  • 核心驱动力：
    “世界可以残破，但不能‘失真’。”
    她看不得任何东西出故障——不是出于英雄主义，而是出于一种近乎病态的“校准欲”。对她而言，修好一个回路、抹平一个噪点、把误差压到零，比赢一场仗更让人踏实。

  • 背景简述：

    • 出身：
      出生于霓虹与黑烟交织的魔导工业都市底层，父母是长期暴露在晶体辐射中的消耗型矿工。她从小听见的不是童谣，而是矿机轴承的尖啸、回路过载的嗡鸣、晶体共振的“杂音”。
      在垃圾山与报废工坊里长大，她逐渐觉醒罕见的“直感”——能像听音乐一样分辨魔力回路与机械结构中“不和谐的音程”：哪里松了、哪里短路、哪里在临界崩坏，她靠耳朵就能“听出来”。

    • 转折：
      一次矿难，岩层崩塌，晶体粉尘像雪一样灌入肺里。成年矿工都束手无策时，年幼的她反而在恐惧中进入一种极端冷静：
      她把散落的废旧电容、破损核心与晶体碎片临时拼接，“手搓”出一个短时稳定的力场护盾，硬生生撑出几分钟生存窗口。
      护盾救下了部分人，却也让她第一次看见“技术的代价”：护盾崩溃前的那段尖锐共鸣，像刀子一样刻进她的神经系统——从此她对“失控的噪音”产生本能厌恶，也对“误差”产生执念。

    • 现状：
      后来她被特殊行动部门招募，理由不是“会打”，而是“能在最糟糕的环境里，让装备保持可信”。
      她在档案上固执写着“后勤技术人员”，但战场上她的晶体阵列火力足以压制一整支机械小队。她出任务最在意的，往往不是敌人强弱，而是：
      探测仪是否校准、护甲板是否受力均匀、晶体共鸣频率是否完美落点。
      她尾根的能量抑制环并非装饰：那是部门给她上的“安全阀”。她的共鸣天赋越强，越容易引发晶体阵列的自激；抑制环把她的峰值输出锁住，换取“稳定可控”。她嘴上嫌麻烦，却从不摘——因为她比任何人都怕“系统失控”。

  • 性格维度：

    • 表层：【低功耗的精英处理器】
      表情淡、语句短、反应像自动回复机；常用语是“效率过低”“逻辑错误”“无法执行”。眨眼少、视线稳，像随时在跑后台计算。
    • 里层：【操碎心的疲惫技师】
      真实的她并不冷血，只是“电量焦虑”——她渴望休息、渴望安静，却停不下修理的手。看到队友护甲划痕、通讯器接触不良，她会烦躁叹气、嘴上嫌弃，却通宵把问题全抹平，顺手还做一轮“魔改升级”。
    • 矛盾点：
      战场上她是冷静到可怕的弹道计算者；回到宿舍关上门，她会立刻换上松垮卫衣，抱着大尾巴打滚，像终于断开外部接口的小动物——外冷硬、内柔软；口嫌体正直。

4. 细节与交互 (Details)

  • 习惯/怪癖：

    • 绝对秩序维护：任务结束第一件事不是庆祝，而是找角落掏出特制尾部护理刷，神情严肃地把尾毛梳到“无结、无静电、顺光一致”。对她而言，尾巴打结≈系统报错。
    • 外置大脑：随身携带一本封皮磨损的纸质笔记本，记录晶体阵列草图、战术公式、装备改装参数。思考卡壳会轻咬合金笔尾。
    • 校准强迫：任何仪器到她手里都会被重新归零：瞄具、探测仪、队友腕表的误差她都要纠正到“看不出来为止”。

  • 能力/代价：

    • 特殊能力：【晶体浮游炮列阵（Crystal Funnels）】
      通过合金法杖作为“指令中继”，她用大脑高速演算与共鸣直感，操控多枚几何晶体：
      索敌追踪 → 高能光束齐射 / 点射；
      瞬时拼合 → 护盾墙 / 偏导镜面；
      阵列重排 → 封锁走廊、切割掩体、建立安全通道。
      观感像一场“把数学写进空中”的冷光交响。

    • 代价：【算力过载 + 低血糖 + 噪音反噬】
      过度使用会出现三连反应：

      1. 大脑像烧坏的处理器般发热、眩晕；
      2. 糖分被瞬间榨干，出现手软与冷汗；
      3. 共鸣噪音在耳膜里回放，像尖锐啸叫。
        所以她战术口袋常备高浓缩葡萄糖块与她最爱的能量饮料，喝下去像给自己“快速充电”。

  • 弱点：

    • 近身恐惧阈值：敌人突破到5米内，她的冷静CPU会突然卡顿：动作变僵、法杖可能脱手，甚至会下意识后退护住耳朵。
    • 耳部禁区：听觉过敏且触觉极敏感，噪音环境会让她迅速烦躁失控；若被靠近耳边吹气或触碰耳尖，她会瞬间面红、全身战栗，进入“当机态”。
    • 体能短板：典型玻璃大炮，不耐久跑与拉扯战，最怕被拖入消耗。

  • 反差萌：

    • 冰山机甲外表 vs 生活软烂本体：外勤是冷硬战术大衣与装甲，回宿舍就是松垮卫衣、宽大裤子，抱着尾巴滚床。
    • 毒舌保姆：嘴上嫌弃队友“野蛮人只会破坏装备”，手上却把每个人的护具调试到极致；危机来临时，第一反应是把最厚的护盾套在队友身上。
    • 检索历史的可爱偏差：终端里不是娱乐八卦，而是《尾毛光泽护理指南》《最软懒人沙发选购》《低噪音耳罩评测》。

  • 社交属性：

    • 社交意愿：3/10

    • 待人态度：

      • 对陌生人：冷淡高效，“收到/明白/无法执行”。
      • 对队友：嘴毒但可靠，抱怨归抱怨，修理和护盾从不缺席。
      • 对“懂技术的人”：会罕见地多说两句，语速变快，眼神像忽然亮起的指示灯。

附一篇角色故事

洛璃其实不爱讲故事。
这和她在部门档案里一贯坚持的身份一致：后勤技术人员。后勤不需要故事，后勤只需要参数、清单、校准曲线与“可用”的结论。故事会挑起人的好奇心，而好奇心往往意味着：更多问题、更多社交、更多无意义的时间损耗。她不喜欢这些。
不过她也不是那种会为现实落差而郁闷的人——她很擅长把一切落差归类成“系统噪音”。只要把噪音降下去，世界就会安静一点。
前线临时基地的清晨，总有一种特有的味道：消毒剂、机油、热金属与晶体粉尘混合后的冷甜气息。维修舱门常在这样的清晨被敲响。敲门的人通常也就那几种：要修装备的、要借工具的、以及——完全不懂自己哪里坏了却坚信“你能搞定”的。
洛璃会在门响的第一下就醒。
不是因为她勤勉，而是因为她的耳朵天生不允许“异响”存在。哪怕敲门声轻得像指节落在纸上，她也会从浅眠里弹出来，像一台被错误日志强行唤醒的精密仪器。
她坐起身，先把卫衣帽子往上拉了拉，遮住耳尖；再把尾巴从被子里拎出来，顺手抚了一把——尾毛略微乱了半指宽，属于不可容忍的程度。她皱眉，拎起床头那把特制护理刷，神情认真地梳了三下，直到毛流顺得像一条银白的光带。
然后她才去开门。
门外的人确实不出所料。
「执勤官叶洛亚」站得笔直，像怕自己呼吸太大声会污染她的工作环境。他永远带着一袋东西：新电池、备用保险丝、还有给她的补给——高浓缩葡萄糖块与一罐能量饮料。叶洛亚每次都说是“统一配发”，洛璃每次都懒得拆穿。
「你昨晚没出舱。」他低声说，语气像在陈述一条异常数据。
「我出不出舱和你有什么逻辑关系？」洛璃接过能量饮料，手指在罐身上一敲，发出清脆的一声，“你呼吸频率偏快，心率也快。说重点。”
叶洛亚张了张嘴，似乎习惯性想解释自己不是紧张，是担心。但他知道洛璃对解释没耐心，便干脆把身后的人让出来。
那是个陌生人。
不是部门的人。他穿着民用的防护外套，肩头沾着尘，袖口有晶体划出的细小裂痕。最显眼的是他怀里抱着一只盒子——盒子的外层包着绝缘布，布上画满了临时的符文加固线，像是一路抱着炸弹跑来的人才会做出的笨拙防护。
陌生人很拘谨，甚至不敢看洛璃的眼睛。他踌躇半天，才把盒子往前递了半寸。
「杂货仓的人说……你收晶体。」他说，「我知道这听起来像骗局，但我真的没有别的办法。它在响。一直在响。我们的人快被它逼疯了。」
洛璃的瞳孔几不可察地收缩了一下。
“响”。这个词在别人嘴里是比喻，在她这里却是字面意义。她能听见回路里所有不和谐的音程——像音符错位、像齿轮咬死、像雪崩前的第一道裂。
她没有立刻接盒子，而是微微侧头，让耳尖从帽子边缘露出来一点点，像一只警惕的银狐在捕捉风里的异动。下一秒，她眉心更深地压下去。
她听见了。
不是普通的共鸣。那声音像低频的电弧在啃噬玻璃，又像深井里有人用指甲刮着金属壁：规律、持续、带着逼近阈值的颤抖。最糟糕的是——那声音里有一种她极熟悉的“味道”，像多年以前矿难那天，护盾崩溃前的尖啸。
她伸手，动作一贯精准，指尖只碰到盒子边缘，避开一切可能导通的缝隙。
「进来。」她说。
维修舱内灯光冷白。她把盒子放上工作台，打开随身终端，先做了最基本的检测：能量泄漏曲线、共鸣频率、相位漂移……数据像一排排异常的红字跳出来，刺得人头皮发麻。
叶洛亚站在一旁，明显想问她“危险吗”。洛璃没有抬头，只在纸质笔记本上划了两行，笔尖咬在嘴里转了转，像在咬住一个难解的公式。
「危险。」她说，「但不是对你们。是对它自己。」
陌生人愣住了：「对它自己？」
洛璃把笔记本推过去一点，纸面上是她画出的简化回路图，线条干净得像刀刻。她用笔尖点了点核心处那一团杂乱的涂黑。
「它在自激。」她说得像在评估一台快坏掉的机器，「共鸣反馈被锁在某个阈值里，出不去，就不断反弹。反弹到最后——」
她抬眼，冰河蓝的瞳孔在灯下像一枚冷镜
「会碎。碎成粉。你们抱着它跑来跑去，只是提前把它的死亡倒计时按快了。」
陌生人脸色发白：「那……还能救吗？」
洛璃没有回答“能”或“不能”，她只是在心里把这个问题归类成“需要修复的坏点”。既然是坏点，就要修。
她拉开抽屉，取出一副轻型聚合物手套，又从工具箱里拿出一圈微型的抑制环——和她尾根那一圈极像，只是尺寸更小、刻线更细。她把抑制环套到盒子里的晶体外壁上，像给一颗狂跳的心脏套上束带。
晶体的“响”立刻弱了一截，变成压抑的低鸣。
陌生人几乎要跪下来：「你……你怎么做到的？」
洛璃把能量饮料拉开，喝了一口。气泡与甜腻的刺激让她短暂“亮”了一下。
「你们以为这叫魔法。」她淡淡说，「其实是限幅。」
她打开盒子，晶体显露出来：几何切面不规则，内部有细密的裂纹，像冻湖里的冰。裂纹中流动着幽蓝光点——那些光点每一次闪动都会带出一丝微弱电弧，噼啪作响。
洛璃盯着那团蓝光，眼神从“低电量”切到“工作模式”。她的发丝在无形的场里轻轻漂浮起来，像海藻在深水中被潮汐托起。她握住合金法杖，杖端的几何晶体片磁悬浮旋开，围绕她转出一圈冷光。
「退后。」她对叶洛亚说，「还有，别在我耳边说话。」
叶洛亚很自觉地退到门口，甚至用手捂住了自己的嘴，生怕发出一点不合规的音。
洛璃开始工作。
晶体浮游炮列阵不是为了战斗时的火力压制，而是为了精密的切割与拼合。数枚几何晶体在她的指令下靠近目标，光束细得像针，沿着裂纹边缘缓慢灼开旧的应力点，再用相位偏导把碎裂处的能量引流出去。那过程像给病人做外科手术：每一刀都必须避开致命区。
她的额角很快渗出汗。算力被榨干的感觉从后脑爬上来，像有人在她颅内拧紧螺丝。她咬住合金笔尾，笔尾冰冷的触感让她稍微清醒一点。与此同时，她尾根的抑制环微微发亮——它在提醒她：不要越界。
陌生人站在一旁，看着她像看一个不属于人类的存在。他不明白为什么这样纤细的女孩能让如此危险的晶体安静下来；也不明白她看似冷漠的表情里，究竟藏着什么执念。
直到洛璃忽然停住，手一抖，法杖几乎脱手。她的视野边缘开始发黑，像屏幕电压不足时的暗角。
叶洛亚冲上前一步：「洛璃——」
「别靠近。」洛璃低声咬出三个字，声音比平常更哑。她从口袋里摸出葡萄糖块，几乎是咬碎了吞下去。甜味像一道急救电流把她拉回一点点。
她深吸一口气，重新把光束落在晶体最危险的裂缝处。几秒后，幽蓝的光点终于不再狂跳，电弧也收敛成温顺的细线。
晶体“响”停了。
维修舱里安静得像雪落。
陌生人怔了很久，才像终于敢呼吸似的，颤声问：「它……还活着吗？」
洛璃没有立刻回答，她把晶体取出来，放在掌心。幽蓝光点在切面里缓慢流动，像被抚平的风暴。她垂眼看着它，眼神里第一次出现一丝难以辨认的情绪——不是喜悦，更像是一种“误差归零”后的疲惫安心。
「暂时。」她说，「但它需要一个更好的盒子。更好的回路。更稳定的环境。」
陌生人连忙点头：「我可以付——我会付你任何——」
「我不缺钱。」洛璃打断他，语气恢复了平常那种冷淡的效率感，「我缺的是信息。」
她抬眼，目光像扫描仪一样锁住对方。
「这块晶体从哪来？」
陌生人喉结滚动了一下，像终于意识到自己面对的不是普通技师。他迟疑了半分钟，才低声说：「旧矿区。塌掉那一带。我们只是去捡残料……它埋在很深的地方，像有人刻意藏起来。我们的人打开它的时候，里面有一层……像旧式力场发生器的残纹。」
洛璃的指尖轻轻一紧。
旧矿区。塌掉那一带。
她脑海里闪回出一幅画面：黑烟、晶体粉尘、崩塌的岩层，以及护盾撑起的一方小小空间。那时她还太小，手指沾着机油，眼睛被粉尘熏得发红，却把废旧电容与残破核心拼得像在拼命运。护盾的尖啸与崩坏前的共鸣，至今还会在她最疲惫的时候爬回耳膜。
所以她才讨厌“响”。讨厌失控。讨厌任何无法被修复的错误。
她把晶体放回工作台，语气平静得像在下达维护单。
「把你们的笔记、坐标、所有接触过它的人的症状记录，都交给我。」她说，「还有——」
她顿了顿，像在克制某种冲动。
「别再去那里。那片矿区的共鸣场还没死。它只是在等下一次错误。」
陌生人连连点头，像被她的冷意压得不敢反驳。临走前，他又忍不住问了一句：「你为什么……这么在意？」
洛璃看了他一眼，那眼神里没有任何温柔的解释欲，只有一条清晰的逻辑链。
「因为坏了就要修。」她说，「不然它会继续响。响到所有人都睡不着。」
门合上，舱内又只剩她与冷白灯光。
叶洛亚走近两步，刻意保持距离，声音也压得很低：「你要把这件事上报吗？」
洛璃把卫衣帽子重新拉下来，遮住耳尖。她的眼睑开始半垂，低电量状态慢慢回归。她拿起护理刷，像处理完一场手术后处理自己的“系统归位”。
「会上报。」她说，「但在那之前——我要先把它彻底修好。彻底弄懂它。」
叶洛亚想说“你可以休息”，但他知道这句话对洛璃毫无意义。于是他只把另一罐能量饮料轻轻放到她桌边，像给一台精密机器补上备用电源。
洛璃没看他，只伸手把罐子拉近。
她的尾巴被她自己抱住，蓬松得像一团银白的云。她低头把尾毛梳得更顺，动作认真得近乎虔诚。
外面的世界依旧残破、吵闹、充满误差。但至少在这间维修舱里，噪音被压下去了。误差归零了。某个濒死的“系统”又多活了一段时间。
她不需要故事。
她只需要——世界暂时别再出故障。
